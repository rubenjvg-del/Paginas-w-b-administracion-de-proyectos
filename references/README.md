## Propósito de las referencias

Estas fuentes se utilizan como material complementario para el análisis y desarrollo del proyecto, especialmente en temas relacionados con:

- Investigación y análisis de mercado.
- Gestión de proyectos.
- Gestión de portafolios.
- Project Management Office (PMO).
- Project Charter.
- Restricciones de los proyectos.
- Factores ambientales empresariales (EEF).
- Activos de procesos organizacionales (OPA).
- Gobierno y generación de valor mediante tecnologías de información.
